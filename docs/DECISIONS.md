# Decision Record — Lore Interlingua

**Function:** A compact index of current and superseded *project decisions*, not a replacement for [Inquiry Graph](https://github.com/BrianMills2718/inquiry-graph)'s source-anchored history. Dates refer to the October 2026 discussion. Where a view changed, preserve both the original and the correction.

| ID | Decision | Status | Evidence / supersession |
| --- | --- | --- | --- |
| D01 | Build a common interlingua between source-lore terminology and visual expression. | **Retain, provisional architecture** | [v0.2 semantic specification](v0.2.md); [Charter](PROJECT_CHARTER.md). No implemented end-to-end compiler. |
| D02 | Aim for fully compositional, minimally arbitrary visual meanings. | **Revised** | Allow iconic representation, traditional symbols, text and deliberate artistic metaphor. See [communication-first](communication-first-design.md). |
| D03 | Commit to an existing upper ontology (e.g. DOLCE) before making examples. | **Rejected as premature** | Prefer example-driven interlingua and grounded distinction rather than importing all of a formal ontology. |
| D04 | Include consciousness, experience, agency, moral responsibility and competing theories without choosing metaphysical winners. | **Retain** | [v0.2](v0.2.md). Formal consistency does not establish doctrinal fidelity. |
| D05 | Separate behind-the-scenes source criticism from audience-facing narrative; initial attribution instead of constant epistemic badges. | **Retain** | [communication-first](communication-first-design.md). |
| D06 | A public lore film initially follows one positive, coherent and specifically scoped account. | **Retain** | [communication-first](communication-first-design.md). Comparative working studies remain allowed. |
| D07 | Every visual feature needs a non-arbitrary, formally defined meaning. | **Rejected** | Artistic choices can decorate, evoke or use selective analogies. Central semantic subjects should nevertheless be identifiable. |
| D08 | Visual communication should eliminate words when possible. | **Revised** | Text and narration are first-class; choose modalities by their contribution to thought and communication. |
| D09 | Viewers must learn the visual language before accessing the series. | **Rejected** | Aim for first-contact comprehension with optional cumulative visual literacy; no prerequisite lessons. |
| D10 | Interlingua → rendering is a one-way pipeline. | **Rejected** | Visual representation, manipulation and discovery feed back into the source model and semantic distinctions. [Thinking instrument](visual-reasoning-instrument.md). |
| D11 | Every finished animation should follow a prescribed script/style/renderer. | **Rejected** | Art direction is irreducible, and a scene may be static, animated, interactive, illustrative or heavily verbal. |
| D12 | Animate slides and call them visual grammar; repeat with a new subject when a film fails. | **Discontinued production pattern** | [Registry](EXPERIMENT_REGISTRY.md): Experiments 003–004, 006 and 007 showed limits. Preserve history without adopting the pattern. |
| D13 | Avoid showing grace as material water/light because it could imply fluid mechanics. | **Rejected as over-literal** | Selective metaphor is integral to art and Catholic symbolism; source-to-image correspondence is contextual, not one-to-one. |
| D14 | The ability to depict atemporal relations is a feasibility question. | **Corrected: settled ability** | [First-principles appraisal](../research/atemporal-visual-reasoning-gate.md), [PR #18](https://github.com/BrianMills2718/lore-interlingua/pull/18). Open questions are quality, reuse, semantic operations and artistic expressiveness. |
| D15 | Kill or save the project via small benchmarks or one unsuccessful transfer case. | **Rejected** | [First-principles appraisal](../research/atemporal-visual-reasoning-gate.md); tests are diagnostic, not universal viability proofs. |
| D16 | Build another polished film as the immediate proof of progress. | **Deferred** | [Current State](PROJECT_STATUS.md) prioritizes source-scoped semantic/visual mapping and a concrete manipulation with a clear interpretive purpose. |
| D17 | Keep `lore-interlingua`, `visual-language`, and `inquiry-graph` conceptually separate. | **Retain** | [Charter](PROJECT_CHARTER.md), [crosswalk](visual-language-crosswalk.md). Define an interface when a real integration requires it. |
| D18 | Treat theological content, inferred consequences, artistic hypothesis, and program tests as equivalent kinds of validation. | **Rejected** | Preserve separate evidence standards and explicit project scopes. |
| D19 | **Comprehension and reusable notation** are the immediate research priorities; a source-scoped conceptual model is **upstream of** the storyboard, which linearizes its explanatory presentation without redefining underlying meaning. | **Retain as research direction; implementation proposed** | [Current Position](PROJECT_STATUS.md), [Experiment 014 PR #37](https://github.com/BrianMills2718/lore-interlingua/pull/37) (**not yet on main**). Distinguish conceptual relationships, notation, explanatory traversal and finished storyboard. |
| D20 | Evaluate candidate notation with Daniel L. Moody's **Physics of Notations** (2009), adapted cautiously to motion and multiple media. | **Provisional design reference, not adopted visual grammar** | [Notation/comprehension guidance](NOTATION_AND_COMPREHENSION.md); [original paper](https://doi.org/10.1109/TSE.2009.67). Do not infer that users understood, that symbols are universal, or that source claims are true. |
| D21 | Treat the subjective reports called **thoughtfeel** as proven evidence that a visual representation improves learning. | **Not established** | Coherent concepts with inspectable facets may inspire designs; formalize external comprehension and reuse tests independently of introspective reports. [Notation guidance](NOTATION_AND_COMPREHENSION.md). |

## Reading rule

Current status and instruction: **[Charter](PROJECT_CHARTER.md) → [Current State](PROJECT_STATUS.md) → [Experiment Registry](EXPERIMENT_REGISTRY.md)**.

Historical versioned specifications and individual experiment "next work" sections preserve earlier plans, many now superseded. They are not automatically current directives. Editing should not silently convert past proposals into accepted principles.

**Attribution:** The user proposed a shared interlingua, compositional meanings, and an artistically flexible visual vocabulary. The assistant suggested visual language as a thinking instrument; the user further developed the reciprocal three-part representation/manipulation/discovery account. This short record is a synthesis of the visible dialogue, not a claim of priority in academic history.
