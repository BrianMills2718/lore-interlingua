## Use

Download and extract the ZIP, then open `index.html` from its root. This redirects to `encyclopedia/index.html`, which runs locally without a server. In the encyclopedia, select Experiment 010 to explore bare ground, grassland and a human gathering. This research instrument is **not** an endorsed model of physical planetary influences.
